TeslaPlay / StreamHub — Complete Build Blueprint
Send this entire document to a website-building AI model. It contains all requirements, exact URLs, colors, and code logic needed. The AI should output ONE single index.html file that works immediately.

1. What We Are Building
A single-file, 100% free streaming website that works in the Tesla Chromium browser while the car is moving. Features:

Live TV (IPTV M3U playlists — default playlist from movitv.pro)
YouTube (search, trending, categories, Shorts, suggestions)
Twitch (channel search with live suggestions, watch live/VOD)
Web Radio (background audio streams)
Browser Games (grid of links + one built-in Canvas game)
No accounts, no paywalls, no npm, no backend. Static. Free hosting via GitHub Pages.
2. Architecture Rules (MANDATORY)
Output is a single index.html file. Put ALL CSS inside a <style> block and ALL JavaScript inside one <script> block. No external CSS/JS files.
No backend, no server, no database. 100% client-side.
All user state saved in window.localStorage. Nothing transmitted anywhere.
Must work when opened directly from file:// and when hosted on GitHub Pages.
Only external dependency allowed is the CDN script: https://cdnjs.cloudflare.com/ajax/libs/hls.js/1.5.17/hls.min.js
Must run with no console errors on first load. Nothing may throw.
3. Tesla Browser Environment — THE KEY FACTS
The Tesla browser is Chromium-based. These behaviors are what make the site work:

Feature	Behavior on Tesla
Native <video> element playing .m3u8 (via Hls.js) or video files	PLAYS while driving. Tesla allows native HTML5 media.
YouTube/Twitch <iframe> embeds	Usually blocked while driving (shows "restricted" screen).
<audio> element	Plays while driving. Used for radio.
Fullscreen overlay div / <canvas>	Renders fine.
Large touch targets	Needed (Tesla has no mouse, only touchscreen scroll wheel + tap).
The bypass technique to implement (IMPORTANT)
For all live stream playback use a fullscreen overlay containing a native <video> element (NOT an iframe). Optionally add a canvas fallback:

Create a hidden <video> element (display:none) that loads the stream with Hls.js.
Create a visible <canvas> element.
On every requestAnimationFrame, draw ctx.drawImage(videoEl, 0, 0, canvasW, canvasH).
If the vehicle blocks the raw video element, the canvas still shows the frames, which tricks the element-scanner.
Provide a toggle button "Canvas / Native" so the user can switch modes.
Always destroy the Hls.js instance and cancel the animation loop when the player closes.

M3U PARSING — exact algorithm
Split text by newlines. For each line starting #EXTINF: capture:

name = text after the LAST comma.
group = from group-title="..." (regex group-title="([^"]*)"), default Other.
logo = from tvg-logo="..." (regex tvg-logo="([^"]*)"), default empty. Then the NEXT non-empty line that does NOT start with # is the channel URL.
CORS HANDLING — must implement
movitv.pro/ and some playlists block CORS. Fetch pipeline:

Try fetch(url) directly.
If it throws, retry via proxy: https://api.allorigins.win/get?url=${encodeURIComponent(url)} then read json().contents.
Show status text so the user knows a proxy was used.
Saved playlists stored in localStorage key shpl as JSON array of {name, url} or {name, text} (for uploaded files).

5.3 YOUTUBE
Search bar #yq + Search button + "Key" button.
"Key" button reveals hidden bar #kbox with #kin input + "Save key" button.
API key stored in localStorage key ytkey. On first click show a JS prompt() stating: "Get a free key at https://console.cloud.google.com/apis/credentials", store whatever they paste.
Live suggestions dropdown under the search box: while typing (≥2 chars), debounce 300ms, call https://www.googleapis.com/youtube/v3/search?part=snippet&maxResults=8&type=video&q=...&key=KEY, render clickable rows (thumb + title) in a .suggestions div. Clicking a suggestion plays it.
Category chips (Trending, Music, Gaming, News, Sports, Movies, Live, Shorts):
Trending: videos?chart=mostPopular&regionCode=US
Category: videos?chart=mostPopular&videoCategoryId=N
Live: search?type=video&eventType=live&q=live
Shorts: search?type=video&videoDuration=short&q=#shorts
Video grid: thumbnail (medium), title, channel name. Click opens player.
Play: https://www.youtube.com/embed/VIDEO_ID?autoplay=1&rel=0 inside the overlay.
ALSO accept pasted YouTube links: extract 11-char ID from v=, youtu.be/, embed/, shorts/, live/.
If no API key: show message telling them to tap Key, but still allow pasted video links to play.
5.4 TWITCH
Search bar #tw + Watch button.
